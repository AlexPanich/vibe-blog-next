# 48. Заявка в авторы: ссылки на тексты

| | |
|---|---|
| Статус | черновик — решения предложены, не обсуждены |
| Lifecycle | `user.md` — заявка на роль автора (если описана там) |
| Источник идеи | спека 42, «Не сделано»: поле «Где почитать ваши тексты» в форме заявки и ссылка в карточке заявки у админа |
| Зависит от | 28 (заявка «стать автором»), 42 (вид страниц заявки) |

## 1. Цель

Сейчас в заявке только текст (`author_requests.text`). В макете — необязательное поле со
ссылкой, а у админа в карточке заявки — эта ссылка и контекст о человеке (давность,
число комментариев).

## 2. Решения (предложены)

1. Поле `link` — одна ссылка, необязательная, `http(s)://`, до 300 символов. Несколько
   ссылок — открытый вопрос.
2. У админа ссылка открывается с `rel="nofollow noopener ugc"` в новой вкладке.
3. Контекст в карточке («читатель с октября 2026 · 23 комментария») — считается из
   существующих данных, поля не нужны; это можно сделать в спеке 42 и без этой.

## 3. Данные

`author_requests.link text NULL` — `ADD COLUMN`, CHECK длины на колонке.

## 4. UI

Форма «Заявка в авторы» (под «О чём хотите писать?»), карточка ожидающей заявки в
«Админ — Заявки в авторы».

## 5. Вне scope

Прикрепление файлов, примеры постов-черновиков в заявке.
