# 37. Маршрут путешествия

| | |
|---|---|
| Статус | черновик — решения предложены, не обсуждены |
| Lifecycle | `post.md` — раздел «Тип» (поля путешествия) |
| Источник идеи | спека 30, «Не сделано»: «Маршрут поездки · 412 км · 3 дня» вместо одной точки |
| Зависит от | 13 (типы постов, карта), 14 (редактор), 25 (правка вне черновика) |

## 1. Цель

В макете у путешествия — маршрут из нескольких точек, длина пути и число дней. Сейчас у
поста одна точка (`posts.lat`, `posts.lng`) и CHECK, который требует её у `travel`.

## 2. Решения (предложены)

1. **Точки маршрута** — от 1 до 20, упорядоченные, у каждой — координаты и необязательная
   подпись («Махачкала», «Гуниб»). Одна точка — как сейчас «Место на карте».
2. **Длина** — сумма расстояний по прямой между соседними точками (формула гаверсинуса),
   считается при показе, не хранится. Подпись — «≈ 412 км по прямой»: по дорогам мы не
   считаем, и честнее это сказать.
3. **Дни** — необязательное число `travel_days` (1–365), вводит автор. Из дат не
   выводим — дат у точек нет.
4. **Редактор** — карта с кликом «добавить точку», список точек с перетаскиванием
   порядка, подписью и удалением. Первая точка по-прежнему обязательна.
5. **Показ** — линия по точкам (`Polyline`), пронумерованные метки (`divIcon`, без
   картинок — см. CLAUDE.md про Leaflet), под картой — «Маршрут поездки · N км · M дней»
   и список подписей точек.
6. **Совместимость** — `posts.lat/lng` остаются первой точкой (их читают карточка,
   фильтры, OpenGraph и CHECK). Остальные точки — в отдельной таблице. Миграция переносит
   нынешнюю точку как первую.
7. **Правка вне черновика** — изменение маршрута — изменение содержимого (спека 25).

## 3. Данные

`post_route_points`: `post_id`, `position`, `lat`, `lng`, `label`; PK `(post_id,
position)`. Первая точка дублирует `posts.lat/lng` — держит транзакция сохранения поста.
`posts.travel_days integer NULL`, CHECK `travel_days IS NULL OR type = 'travel'` — на
колонке, `ADD COLUMN` руками.

## 4. UI

`domains/posts/components/map/` — карта маршрута и редактор точек, `PostHead`/блок карты
на странице поста. Макет блока «Маршрут поездки» уже есть в Pencil (страница поста);
редактор маршрута — нарисовать.

## 5. Вне scope

Маршрут по дорогам (нужен внешний сервис), импорт GPX, даты у точек, фото на точках.

## 6. Открытые вопросы

- Длина «по прямой» устраивает или нужен расчёт по дорогам (OSRM или похожий сервис)?
- Лимит точек — 20 достаточно?
- Импорт трека GPX — нужен сразу?
