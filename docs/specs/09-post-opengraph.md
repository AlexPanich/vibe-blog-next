Решения приняты без обсуждения (человек попросил работать без остановки), подтверждены на проверке 2026-10-27.

## 1. Цель

Ссылка на пост в мессенджере или соцсети показывает карточку: заголовок, начало текста,
автор, рубрики. Картинка 1200×630 генерируется кодом.

## 2. Решения

1. **`opengraph-image.tsx` у `posts/[id]`** — соглашение Next, файл живёт в `app/`. Сама
   разметка — `PostOgImage` в домене постов; файл в `app/` только грузит данные.
2. **Только опубликованный пост**: черновик и всё прочее — 404, как страница. Превью не
   раскрывает неопубликованное.
3. **Описание** — первые 160 символов текста без разметки: `description` и
   `og:description` в `generateMetadata`, `og:type = article`.
4. **Шрифт — Geist из комплекта `next/og`**: кириллица в нём есть (проверено картинкой),
   скачивать свой не нужно. Жирного начертания нет — заголовок обычным весом, крупно.
5. **Цвета — тёмная палитра из `tokens.css`, заданная прямо**: Satori не знает
   CSS-переменных. Брендовая полоса сверху.
6. **Превью ленты, главной и автора не делаем** — только пост.

## 3. Проверено

- `/posts/3/opengraph-image-…` — 200, `image/png`, кириллица отрисована.
- Черновик — 404.
- На странице поста `og:image` с размерами и `alt`, `description` без разметки.
