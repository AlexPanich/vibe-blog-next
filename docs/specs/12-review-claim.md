# 12. «Взять на ревью» и перехват

| | |
|---|---|
| Статус | done |
| Lifecycle | `docs/lifecycles/post.md` — раздел «Ревью» |
| Источник идеи | next-2, спеки 16 и 21 «Очередь ревью, перехват» — взята задача, не реализация |

Решения приняты без обсуждения (человек попросил работать без остановки), подтверждены на проверке 2026-10-27.

## 1. Цель

Когда модераторов несколько, двое могут открыть один пост и разбирать его параллельно.
Модератор «берёт пост на ревью», остальные это видят и не решают за него. Admin может
перехватить зависшее ревью.

## 2. Решения

1. **Не статус, а колонка `posts.reviewerId`** (+ `reviewStartedAt`). У next-2 —
   отдельный статус `reviewing`, но тогда право решать зависит от того, *кто* взял пост: это
   отношение, и в ролевую таблицу `POST_TRANSITIONS` оно не ложится — от того же мы ушли в
   спеке 01. Статус остаётся `moderating`, ревью — мягкая блокировка внутри него.
2. **Брать на ревью необязательно**: по свободному посту решение принимается сразу, как
   раньше.
3. **Решает** модератор, если пост свободен или взят им; **admin — всегда** (это и есть
   перехват). Кнопка «Перехватить» у admin делает перехват явным: пост переходит на него.
4. **Ревьюер может отпустить** пост.
5. **Любая смена статуса снимает ревьюера** — `changePostStatus` обнуляет колонки.
6. **Проверка ревьюера — в том же UPDATE, что смена статуса** (`reviewGuard`), а в
   `breakIfCant` — только роль. Устаревшая страница получает «пост уже изменился» (409), а
   не 403 — по тому же принципу, что статусы (`post.md`).
7. **Автор видит**, что пост смотрит модератор, и его имя — как в next-2.
8. **В историю модерации взятие на ревью не пишется** — история про решения.
9. Автоматического снятия зависшего ревью по таймеру нет — для этого перехват admin.

## 3. Проверено

Свободный пост — «Взять» и форма; взятие; решение второго модератора с устаревшей
страницы — 409, статус не изменился; второй модератор видит ревьюера, без формы и
перехвата; пометка «На ревью: …» в очереди; автор видит ревьюера; перехват admin;
«Отпустить»; одобрение снимает ревьюера.
