# 11. Публичный профиль автора

| | |
|---|---|
| Статус | done |

| Источник идеи | next-2, спеки 10 «Профиль: аватар, био» и 11 «Публичная страница пользователя» |

Решения приняты без обсуждения (человек попросил работать без остановки), подтверждены на проверке 2026-10-27.

## 1. Цель

`/authors/[id]` сейчас — таблица заголовков с учебными кнопками «Показать ссылку». Спека
делает из неё страницу автора: кто это, сколько опубликовано, как оценивают, последние
посты. В профиле появляется «О себе».

## 2. Решения

1. **«О себе»** — до 500 символов, простой текст (не markdown: это подпись, а не пост),
   правится в `office/profile`. Колонка `users.bio`, better-auth её не знает.
2. **Аватар — заглушка с первой буквой имени**: загрузки картинок нет (тяжёлая фича из
   третьего списка). Компонент `UserAvatar` заменится на картинку, когда она появится.
3. **Шапка страницы**: аватар, имя, «О себе», «С нами с», число опубликованных постов,
   средняя оценка (взвешенная, как на странице авторов — спека 06/07).
4. **Посты — последние 12 опубликованных карточками** и ссылка «Все посты в ленте» на
   `/posts?author=id`: там уже есть прокрутка, поиск и сортировки — вторую ленту на
   странице автора не строим.
5. **Страница есть у любого пользователя**, как и раньше; без постов — «Постов пока нет».
   Неизвестный id — 404.
6. **«Последний заход» не делаем**: запись на каждый запрос (у next-2 — с троттлингом 60 с)
   ради малого эффекта.
7. Учебные `PostLinkToggle` / `PostEditLink` со старой страницы больше не используются;
   файлы не удалены — похоже, это материал домашнего задания.
