# 34. Сортировки ленты: «Популярные», «Обсуждаемые», «Мои подписки»

| | |
|---|---|
| Статус | черновик — решения предложены, не обсуждены |
| Lifecycle | `post.md` — раздел «Лента подписок» (если «Мои подписки» станут вкладкой `/posts`) |
| Источник идеи | спека 30, «Не сделано»: сегменты ленты из макета |
| Зависит от | 05 (лента), 07 (оценки), 15 (комментарии), 19 (подписки), 22 (живая лента) |

## 1. Цель

В макете сегменты ленты «Новые, Популярные, Обсуждаемые, Мои подписки», у нас — «Новые,
Лучшие, Старые, По автору». Новых полей не нужно: всё считается по оценкам, комментариям
и подпискам.

## 2. Решения (предложены)

1. **Сегменты** — «Новые», «Популярные», «Обсуждаемые», «Мои подписки». «Старые» и «По
   автору» уходят из сегментов в список «Сортировка» рядом с фильтрами (как тип и
   период) — не пропадают.
2. **«Популярные»** — по сумме оценок за период с поправкой на их число: средняя по
   Байесу (`(C·m + Σ) / (C + n)`, `m` — средняя по сайту, `C` = 5), чтобы пост с одной
   пятёркой не обгонял пост с двадцатью четвёрками. Период по умолчанию — месяц. Нынешняя
   «Лучшие» (по средней) становится этим.
3. **«Обсуждаемые»** — по числу видимых комментариев к посту (без удалённых и скрытых,
   включая комментарии к фото) за период; при равенстве — новее выше.
4. **«Мои подписки»** — гостю не показывается. Вошедшему — та же выборка, что «Моя
   лента» (`office/feed`, спека 19): подписки на авторов и рубрики. Вариант: сегмент —
   просто ссылка на `office/feed` (просто), или вкладка внутри `/posts` (одна лента вместо
   двух). Предлагаю ссылку.
5. **Живая лента** (спека 22) — плашка «N новых постов» только у «Новых»: в других
   сортировках новый пост не встаёт наверх.
6. **URL** — `sort=popular | discussed`, старые `sort=rating` ведут на `popular`.

## 3. Данные

Нет. Индекс `comments(post_id)` уже есть; для «Обсуждаемых» — агрегат как
`ratingAggregate()`.

## 4. UI

`domains/posts/dto/postFeedRequests.ts` (`FEED_SORTS`), `shared/loadFeed.ts`
(`feedOrder`), `components/FeedSortTabs.tsx`.

## 5. Вне scope

Персональные рекомендации, «в тренде» по просмотрам (просмотры не считаем).

## 6. Открытые вопросы

- Формула «Популярных»: Байес по оценкам или смесь оценок, избранного и комментариев?
- «Мои подписки» — ссылка на `office/feed` или вкладка `/posts`?
- Период по умолчанию для «Популярных» и «Обсуждаемых»: неделя или месяц?
