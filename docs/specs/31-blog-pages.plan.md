# 31. Рубрики и страницы о блоге — план

Спека — `31-blog-pages.md`. Макет — документ Pencil у автора (не в репозитории), фреймы:
«Рубрики», «О блоге», «Контакты» — десктоп, «— моб.» и «— тёмная» к каждому (12 фреймов).
Перед вёрсткой шага открыть нужный фрейм через MCP `pencil` (`get_app_state` →
`execute` с `Get(id, {depth: 4})` и `TakeScreenshot`), размеры и отступы брать оттуда.
Шрифты, цвета и радиусы — токены `tokens.css`, иконки lucide из макета → `@tabler/icons-react`.

## Что в макете (сжато)

**Рубрики, десктоп.** Заголовок `h1` «Рубрики» + подпись «12 рубрик — выберите, о чём читать,
и подпишитесь на любимые». Секция «Больше всего постов» (справа серым «по числу
опубликованных»): сетка 3×2 плиток высотой 220, радиус 28, фон `--<tone>-soft`. В плитке
сверху — название (display, 28/700) и пилюля подписки справа («+ Подписаться» / «✓ Вы
подписаны», обводка), снизу — число (display, 64/700) + «постов» и круглая кнопка 52px цвета
тона со стрелкой `↗`. Секция «Остальные рубрики» («по алфавиту»): сетка 3 колонки строк —
обводка `--rule`, радиус 20, точка цвета тона 12px, название + «N постов», круглая кнопка
подписки 40px (`+` / `✓`).
**Рубрики, телефон.** Подпись короче («…выберите, о чём читать»), плитки 2 колонки высотой
150, стрелки нет — вся плитка ссылка, вместо пилюли — круглая кнопка подписки внизу справа.
Остальные — одной колонкой.
**Текстовые страницы, десктоп.** Слева узкое меню раздела: «О блоге, Правила, Модерация,
Контакты» с иконками, активный пункт — подложка. Справа колонка текста: kicker коралловым
капсом («О БЛОГЕ»), `h1`, крупный lead, дальше `h2`, списки, цитата с коралловой чертой.
Внизу «О блоге» — плашка `--sun-soft`: «Хотите писать в Vibe?» / «Расскажите о себе —
заявку рассмотрят за пару дней» / кнопка «Стать автором».
**Текстовые, телефон.** Меню раздела — горизонтальные чипы под шапкой (активный — тёмный).
**Контакты.** Тот же каркас; под текстом две карточки в ряд (на телефоне — столбиком):
«Почта» (иконка, «Ответим в течение пары рабочих дней», ссылка-адрес) и «Написать
администрации» («Личное сообщение в кабинете — нужно войти в аккаунт», тёмная кнопка
«Написать»).
**Шапка** — «Посты, Авторы, Рубрики, О блоге». **Подвал**: десктоп — «Правила, Модерация,
Контакты, RSS»; телефон — «О блоге, Правила, Модерация, Контакты, RSS» строкой, под ней знак
с подписью.

## Решения плана (в спеке не было)

1. **Маршруты — четыре папки в группе** `app/(public)/(about)/{about,rules,moderation,contacts}/page.tsx`
   с общим `app/(public)/(about)/layout.tsx` (меню раздела + колонка). Не `[slug]`:
   динамический сегмент в корне ловил бы любой url, а `typedRoutes` не знал бы `/about`.
2. **Новый домен `site-pages`** — страницы о блоге: реестр, загрузка markdown, компоненты.
   Это не универсальный код и не чужой домен, поэтому не корневой `components/`.
3. **Заголовок, kicker и description — в реестре** (`domains/site-pages/shared/sitePages.ts`),
   в `.md` — только lead и тело. Lead — первый абзац файла, выделяется CSS.
4. **Свой рендер markdown** (`SitePageMarkdown`), не `PostMarkdown`: тот открывает все ссылки в
   новой вкладке и сдвигает заголовки. Здесь `##` → `h2` как есть, ссылка на `/…` — `Link`,
   внешняя — `target="_blank" rel="noopener noreferrer"`. `remark-gfm`, `skipHtml`.
5. **Файлы `.md` в рантайме** читает `fs` по `process.cwd()/src/content`. Standalone-сборка их
   не трассирует — в `Dockerfile` (рантайм) добавить `COPY src/content ./src/content`.
6. **Подписка на `/tags` — одним запросом.** Новый action `myTagFollowIdsAction` → `{ ids:
   number[] }` (все мои подписки на рубрики), вызывается один раз в клиентском `TagsBoard`;
   кнопки получают состояние оттуда. Переключение — существующий `followTagAction`. Гостю
   кнопок нет (спека п. 1). Ошибка (лимит 30 подписок) — `showToast`.
7. **Плитка — ссылка без вложенной кнопки.** Плитка `div` c растянутой ссылкой
   (`a::after { inset: 0 }`), кнопка подписки поверх (`position: relative; z-index: 1`) —
   `button` внутри `a` невалиден.
8. **Порядок.** Рубрики с `postsCount > 0`. Топ — 6 по убыванию числа, при равенстве
   `localeCompare('ru')`. Остальные — `sortTags`. Если рубрик ≤ 6 — секции «Остальные» нет.
   Тон — `tagTone(id)`; у `plain` фон плитки `--paper-tint`, кнопка `--ink`.
9. **«О блоге» в шапке активен** на всех четырёх страницах раздела (`isActivePath` не
   подходит — свой список путей в `TopMenu`).
10. **«Все рубрики» на главной** — в макете нет: последней ссылкой в `.ui-home-chips`, вид
    `.ui-home-section__more` (текст со стрелкой), ведёт на `/tags`.
11. **«О блоге» в подвале** — только на телефоне (≤ 720px), на десктопе он в шапке. RSS не
    добавляем до спеки 32.
12. **Призыв на «О блоге»** — `HomeWriteLink` с подписями «Написать пост» / «Подать заявку в
    авторы» / «Стать автором»; подзаголовок плашки — один для всех. `HomeWriteLink` отдать
    через `domains/posts/exports/HomeWriteLink.ts`.
13. **Env контактов** — `src/config/contacts.ts`: `email` (строка или `null`), `userId`
    (только каноническое положительное целое, иначе `null`). Нет обоих — карточек нет, есть
    один — одна карточка. Ссылка «Написать» — `/office/messages/new?to=<id>`.
14. **Статика/динамика.** `/contacts` — `dynamic = 'force-dynamic'` (env в рантайме),
    `/tags` — `force-dynamic` (счётчики), три остальные — без явного `dynamic`.

## Шаги

### 1. Конфиг и окружение
- `src/config/contacts.ts` — `contactsConfig = { email, userId }` из `CONTACT_EMAIL`,
  `CONTACT_USER_ID` (п. 13), `import 'server-only'`, как `config/auth.ts`. Функций в
  `config/` нет — разбор id выражением на месте (регэксп `^[1-9]\d*$`).
- `.env.example` — блок «Необязательно. Контакты на /contacts», оба ключа с примерами
  (`hello@vibe.example`, `1`).
- `render.yaml` — `CONTACT_USER_ID: "1"` с комментарием: Алиса — первая в
  `seed-demo/people.ts`, база на стенде всегда свежая, id = 1. Проверить по dev-базе
  (`mcp sql-dev`: `select id from users where email='alice@example.com'`) — если в dev id
  другой, это не важно, но для стенда опираемся на порядок сида.
- `Dockerfile`, стадия рантайма — `COPY --chown=node:node src/content ./src/content` (п. 5).

### 2. Домен `site-pages`
- `shared/sitePages.ts` (без пометки): `SITE_PAGES` — массив `{ slug: 'about' | 'rules' |
  'moderation' | 'contacts', href: Route, label, kicker, title, description, icon }`, тип
  `SitePageSlug`. Иконки tabler: `IconInfoCircle`, `IconScale` (или `IconListCheck`),
  `IconShieldCheck`, `IconMail` — сверить с макетом. Иконки — React-компоненты, поэтому
  реестр данных без иконок, а иконки — словарём в `SitePagesNav`.
- `shared/loadSitePage.ts` (`server-only`): `cache((slug) => fs.readFile(...))`.
- `components/SitePageMarkdown.tsx` (п. 4).
- `components/SitePageArticle.tsx` — серверный: kicker, `h1`, `SitePageMarkdown`, `children`
  после текста (карточки, призыв).
- `components/SitePagesNav.tsx` — `'use client'` (`usePathname`): на десктопе вертикальное
  меню, на телефоне те же ссылки чипами со скроллом (одна разметка, вид — CSS).
- `components/SiteContacts.tsx` — серверный, карточки «Почта» и «Написать администрации»;
  данные — пропсами из page (`email`, `userId`), не читает config сам. Кнопка — `ButtonLink`
  или `Link` с классом кнопки макета.
- `components/SiteWriteCta.tsx` — плашка «Хотите писать в Vibe?» (п. 12).

### 3. Тексты `src/content/*.md`
Черновики пишет агент, автор правит. Первый абзац — lead. Только `##`, списки, цитаты, ссылки.
- `about.md` — по макету: lead, «Как это устроено» (список из трёх пунктов + цитата), «Кто мы»
  (ссылка на `/rules`).
- `rules.md` — что можно публиковать (свои тексты и фото, источник у перевода), что нельзя
  (спам, реклама, чужие тексты, оскорбления), комментарии и сообщения, последствия:
  отклонение, блокировка поста, бан. Основа — `docs/lifecycles/post.md`, `comment.md`,
  `user.md` (разделы искать `grep -n`).
- `moderation.md` — очередь и «взять на ревью», что проверяем, отклонение с причиной и
  повторная отправка, блокировка поста, жалобы на комментарии и что с ними бывает. Основа —
  пост «Как устроена модерация в Vibe» (`scripts/seed-demo/posts-others.ts:795`),
  `docs/lifecycles/post.md`, `report.md`. Только то, что реально работает в коде.
- `contacts.md` — по макету: lead + абзац про кнопку «Пожаловаться».

### 4. Страницы раздела
- `app/(public)/(about)/layout.tsx` — `.ui-site-pages` (сетка: меню + колонка), `SitePagesNav`.
- `about/page.tsx`, `rules/page.tsx`, `moderation/page.tsx`, `contacts/page.tsx` — по 10 строк:
  `metadata` из реестра (`title`, `description`), `SitePageArticle slug=…`. В `about` — дочерний
  `SiteWriteCta`, в `contacts` — `SiteContacts` с `contactsConfig`.
- Проверить: `/about` и т. д. открываются, `/office/moderation` не задет, неизвестный путь —
  по-прежнему 404.

### 5. Страница `/tags`
- `domains/tags/actions/tagFollowActions.ts` — `myTagFollowIdsAction` (`actionAuthClient`,
  без input): `select tagId from tag_follows where userId`.
- `domains/tags/dto/tagResources.ts` — ресурс плитки `{ id, name, slug, postsCount }`
  (посмотреть, нет ли подходящего; скил `resource`).
- `domains/tags/components/directory/` — `TagsBoard` (`'use client'`: грузит подписки,
  держит `Set` id, рисует обе секции), `TagTile`, `TagRestRow`, `TagFollowToggle` (пилюля на
  десктопе / круглая на телефоне — одна кнопка, подпись в `.ui-pill__label`-подобном span,
  прячется CSS; `aria-label` с названием рубрики).
- `app/(public)/tags/page.tsx` — `metadata { title: 'Рубрики', description }`, `tagsWithCounts()`,
  фильтр и разбиение (п. 8) на сервере, в `TagsBoard` — `resource` двух списков. Заголовок и
  подпись (`plural`: «рубрика/рубрики/рубрик») — в page. Нет рубрик с постами — `.ui-empty`.
- Ссылки плиток и строк — `/posts?tag=<slug>`.

### 6. Навигация
- `TopMenu.tsx` — пункты «Рубрики» (`/tags`) и «О блоге» (`/about`, активен на четырёх путях,
  п. 9).
- `SiteFooter.tsx` — «О блоге» (класс `ui-footer__mobile-only`), «Правила», «Модерация»,
  «Контакты»; «Посты, Авторы, Стать автором» убрать. Ссылки брать из `SITE_PAGES`
  (`domains/site-pages/exports/sitePages.ts`).
- Главная — «Все рубрики» (п. 10).

### 7. CSS (`src/theme/layout.css`)
- Подвал на телефоне: ссылки строкой сверху, знак ниже (`flex-direction: column-reverse`,
  выравнивание влево); `.ui-footer__mobile-only` — `display: none` выше 720px.
- `.ui-tags-*`: шапка, секции с правой серой подписью, сетка плиток 3 → 2 колонки, плитка
  (тоны по `data-tone`, как `.ui-post-row__thumb`), кнопка-стрелка (на телефоне скрыта),
  строки 3 → 1 колонка, точка тона.
- `.ui-site-pages`: сетка `~15rem | 1fr`, на телефоне — одна колонка, меню — чипы со скроллом
  (как `.ui-feed-chips`). Колонка текста — `max-width: var(--measure)`. Kicker, lead.
- Типографика тела: правила `.ui-post__body .ui-prose …` (h2–h5, blockquote, отступы)
  распространить на `.ui-site-page__body .ui-prose` — дописать второй селектор, не копировать.
- Карточки контактов и плашка призыва — по макету, обе схемы через токены.
