# 06. Страница авторов

| | |

## 1. Цель

`/authors` сейчас выводит всех пользователей — с постами и без, модераторов без единого
поста тоже. Спека делает из неё список авторов: кто публикуется, сколько опубликовано,
куда перейти.

## 2. Решения (приняты без обсуждения, подтверждены 2026-10-27)

1. **Автор — пользователь хотя бы с одним опубликованным постом.** Роль `author` без
   постов в список не попадает: пустая карточка в сетке — шум. Забаненный с
   опубликованными постами остаётся: его контент в ленте остаётся (спека 02), значит, и
   автор виден.
2. **Счётчик — только опубликованные посты**, тот же, что видит гость в ленте.
3. **Сортировка: по имени (по умолчанию) или по числу постов**, в `?sort=name|posts`.
   Алфавит — `sort_ru` (спека 05). При равном числе постов — по имени. Сортировка по
   рейтингу и средний рейтинг в карточке добавлены вместе с оценками (спека 07).
4. **Карточка**: имя, «Постов: N», «С нами с <дата>», ссылки «Посты в ленте»
   (`/posts?author=id`) и «Страница автора» (`/authors/[id]`). Без кнопки «Подробнее»:
   прятать дату регистрации незачем. Карточка серверная.
5. **Без пагинации**: авторов на порядок меньше постов. Неизвестный `sort` — по имени.
6. `/authors/[id]` не трогаем — она переделывается в фиче «публичный профиль».

## 3. План

- `domains/users/dto/userRequests.ts` — `authorsFilterDto { sort: enum, catch 'name' }`.
- `domains/users/dto/userResources.ts` — `authorResource` += `id`, `postsCount`.
- `AuthorCard` — серверный компонент без состояния.
- `app/(public)/authors/page.tsx` — core-select `users` ⋈ `posts (published)`, `count`,
  `groupBy users.id`, сортировка по `sort_ru(name)` или `count desc, sort_ru(name)`;
  переключатель сортировки — `.ui-filter`-ссылки.
- Проверка: в списке только авторы с опубликованными постами, счётчики совпадают с
  фильтром ленты по автору, обе сортировки, ссылки карточки.
