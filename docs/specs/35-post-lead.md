# 35. Подзаголовок поста (lead)

| | |
|---|---|
| Статус | черновик — решения предложены, не обсуждены |
| Lifecycle | `post.md` — поля поста; правка вне черновика (спека 25) |
| Источник идеи | спека 30, «Не сделано»: подзаголовок под заголовком на странице поста |
| Зависит от | 14 (редактор), 25 (правка вне черновика), 30 (шапка поста, карточка) |

## 1. Цель

В макете под заголовком поста — одна-две строки подзаголовка. Сейчас поля нет: в карточке
показывается выдержка из начала текста (`postText.ts`), на странице поста — ничего.

## 2. Решения (предложены)

1. **Поле `lead`** — необязательное, 20–200 символов, обычный текст без markdown.
2. **Где видно** — страница поста под заголовком (`PostHead`), карточка вместо выдержки,
   «Выбор редакции», OpenGraph `description`, RSS (спека 32). Нет lead — как сейчас:
   выдержка из текста.
3. **Редактор** — поле «Подзаголовок» под заголовком, со счётчиком символов и подсказкой
   «Пара фраз, о чём пост — видно в ленте и в превью ссылки».
4. **Правка вне черновика** — как правка текста (спека 25): у опубликованного поста
   изменение подзаголовка отправляет пост на модерацию? Предлагаю — да, как любое
   изменение содержимого.
5. **Модерация** — подзаголовок виден в очереди и в истории изменений, как заголовок.

## 3. Данные

`posts.lead text NULL`, CHECK `length(lead) BETWEEN 20 AND 200` или NULL. Миграция —
`ADD COLUMN` руками (на `posts` ссылаются другие таблицы, см. CLAUDE.md). `postResource` —
поле `lead`; `withCardData` берёт `lead ?? excerpt`.

## 4. UI

`domains/posts/components/editor/` — поле формы, `PostHead`, `PostCard`, `PostFeatured`,
`opengraph-image.tsx` и `generateMetadata` страницы поста. Макет — уже есть (шапка поста в
спеке 30).

## 5. Вне scope

Форматирование в подзаголовке, автогенерация lead из текста.

## 6. Открытые вопросы

- Правка lead у опубликованного поста — снова на модерацию или нет?
- Обязателен ли lead для публикации?
