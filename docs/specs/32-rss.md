## 1. Цель

Читать Vibe в RSS-читалке. Новых данных не нужно — те же опубликованные посты, что в
ленте.

## 2. Решения (предложены)

1. **`/rss.xml`** — RSS 2.0, 30 последних опубликованных постов по `publishedAt`.
2. **Элемент** — заголовок, ссылка на пост, `guid` (ссылка, `isPermaLink`), `pubDate`
   (`publishedAt`), автор (`dc:creator` — имя, email не отдаём), рубрики (`category`),
   описание — выдержка из `postText.ts` (то же, что в карточке). Обложка — `enclosure`
   с вариантом 800px. Полный текст не отдаём: читать — на сайте.
3. **По рубрике и автору** — `?tag=<slug>`, `?author=<id>` — те же фильтры, что в ленте
   (`postFeedFilterDto`), остальные параметры игнорируются.
4. **Кэш** — `revalidate` 10 минут; route не трогает сессию — одинаков для всех.
5. **Ссылки** — `<link rel="alternate" type="application/rss+xml">` в `<head>` публичного
   layout; иконка RSS в подвале; на странице рубрики (спека 31) и профиле автора — «RSS
   рубрики» / «RSS автора».
6. **Rate limit** — общий из `proxy.ts`; файл с расширением `.xml` через proxy не идёт
   (см. CLAUDE.md про загрузки) — проверить, нужен ли отдельный лимит.

## 3. Данные

Нет.

## 4. UI

`app/rss.xml/route.ts` (вне `(public)`: XML, без layout). Сборка XML — функция в
`domains/posts/shared/`, экранирование — вручную или маленьким хелпером в `core/`.

## 5. Вне scope

Atom, JSON Feed, полный текст поста в ленте, лента комментариев.
