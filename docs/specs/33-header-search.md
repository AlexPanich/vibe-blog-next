## 1. Цель

Сейчас кнопка-лупа в шапке просто открывает ленту, а поле поиска — уже там. Нужно искать
сразу из шапки на любой странице (публичная часть и кабинет — шапка общая). Сам поиск уже
есть (`postFeedFilterDto.search`, `lower_ru`).

## 2. Решения

1. **Раскрытие поля.** По клику на лупу поле раскрывается в шапке: на десктопе — на месте
   меню (`TopMenu` скрыт, пока поле открыто), на узкой шапке — поверх всей строки (бренд
   и иконки скрыты, справа — крестик). Фокус ставится в обработчике клика, поэтому
   клавиатура на iOS открывается сразу. Один компонент на все ширины — *обсуждено*:
   вариант «лупа ведёт в `/posts?focus=search`» отклонён, iOS не открывает клавиатуру при
   программном фокусе после навигации.
2. **Отправка.** Enter — переход в `/posts?search=<запрос>` (GET-форма, `name="search"`).
   Фильтры ленты не переносятся: поиск из шапки — новый поиск по всем постам.
   Пустой запрос — просто `/posts`. Поле после перехода закрывается.
3. **Закрытие.** Esc, крестик или клик мимо поля — поле закрывается, фокус возвращается
   на лупу. Введённый текст не сохраняется.
4. **Хоткей `/`** открывает поле. Не срабатывает, когда фокус в `input`, `textarea`,
   `select` или `contenteditable` (редактор поста, сообщения) и при нажатом модификаторе.
5. **В ленте `/posts`** (точное совпадение пути) лупа и `/` не раскрывают поле в шапке, а
   прокручивают к полю `FeedSearch` и ставят в него фокус: там поиск сохраняет фильтры,
   двух полей одновременно на экране нет — *обсуждено*. Ленты `/tags/<slug>` и профиль
   автора — обычное поведение (п. 1).
6. **Без JS** лупа остаётся ссылкой на `/posts`, как сейчас: клиентский компонент
   перехватывает клик после гидрации.
7. **Что ищем** — то же, что в ленте (заголовок и текст поста). Подсказки при вводе,
   авторы и рубрики — вне scope, *обсуждено*.

## 4. UI

- `components/layout/HeaderSearch.tsx` — клиентский компонент (`'use client'`,
  `client-only`): кнопка-лупа (ссылка на `/posts`) + форма GET на `/posts`. Подключается в
  `SiteHeader` вместо текущей ссылки. Раскрытое состояние — атрибут на `.ui-masthead`
  (например `data-search="open"`), скрытие меню и иконок — CSS по нему.
- Состояние «открыто» есть только после действия пользователя, на сервере всегда
  закрыто — расхождения при гидрации нет (скил `hydration`).
- Фокус поля ленты: у `FeedSearch` — `id` на `input`, `HeaderSearch` ищет его по `id`
  (`document.getElementById`), отдельного контекста не нужно.
- Стили — `.ui-search` переиспользовать, раскладка шапки — в `layout.css`, цвета из
  токенов.
- Макет — дорисовать открытое состояние шапки (десктоп и телефон) в Pencil до вёрстки.

## 5. Вне scope

Подсказки при вводе (action с rate limit, выпадающий список, поиск по авторам и рубрикам) —
кандидат в отдельную спеку. Отдельная страница результатов.

## Отклонения при реализации

- **`HeaderSearch` рисует всю строку шапки**, а не только лупу: поле должно встать в трек сетки
  на место меню, поэтому бренд, `TopMenu` и правые иконки `SiteHeader` передаёт слотами.
  Атрибут `data-search="open"` — на `.ui-masthead__row` (корень компонента), а не на
  `.ui-masthead`. Тосты (`NotificationToasts`, `MessageToasts`) вынесены из строки в `header`.
- **Клик мимо поля** закрывает его без возврата фокуса на лупу: фокус уходит туда, куда
  кликнули. Возврат на лупу — только для Esc и крестика.
- **Отправка — `router.push`**, а не нативный GET (мягкая навигация: живой канал и тосты не
  перезапускаются); форма остаётся GET-формой на `/posts` для семантики. Кнопки «Найти» нет —
  Enter и «Поиск» на клавиатуре телефона.
- **Хоткей `/`** срабатывает и по физической клавише (`code === 'Slash'`) — на русской раскладке
  она даёт «.»; не срабатывает и в открытом диалоге (`[role="dialog"]`).
- **Повторный клик по лупе** при открытом поле закрывает его; Ctrl/Cmd/Shift-клик — обычная
  ссылка на `/posts`.
- **`/tags/<slug>` нет** (п. 5 спеки): лента рубрики — `/posts?tag=…`, то есть путь `/posts`, и
  лупа там ведёт в поле ленты. Поиск из шапки на других страницах сбрасывает фильтры
  (`/tags?type=photo` → `/posts?search=…`).
- **Высота поля** в шапке — 40px, как у круглых иконок: с полем `.ui-search` обычной высоты
  строка шапки при открытии росла на 4–5px.
- Макет — фрейм «Шапка — поиск (спека 33)» в документе Pencil.
