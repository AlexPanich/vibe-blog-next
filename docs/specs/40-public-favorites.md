# 40. Избранное в профиле

| | |
|---|---|
| Статус | черновик — решения предложены, не обсуждены |
| Lifecycle | `post.md` — раздел «Избранное»; `user.md` — настройки профиля |
| Источник идеи | спека 30, «Не сделано»: вкладка «Избранное» в профиле автора |
| Зависит от | 10 (избранное), 11 (профиль), 26 (блокировка), 30 (вкладки профиля) |

## 1. Цель

В макете профиля есть вкладка «Избранное». У нас избранное личное: «закладка личная,
публичного счётчика нет» (`post.md`). Показывать его другим — решение о приватности, по
умолчанию оно должно оставаться закрытым.

## 2. Решения (предложены)

1. **Настройка** «Показывать моё избранное в профиле» в `office/profile`, по умолчанию
   выключена. Включение касается всех закладок, по одной не выбираем.
2. **Вкладка «Избранное · N»** в профиле — только если настройка включена и в избранном
   есть опубликованные посты. Те же карточки и лимит 12, что у постов автора; дальше —
   «Всё избранное» на отдельной странице `/authors/<id>/favorites` (в ленту не ведёт:
   фильтра «избранное пользователя» в ленте нет).
3. **Порядок** — по дате добавления в избранное, новые сверху.
4. **Видимость** — только опубликованные посты; у того, кто владельца заблокировал, —
   ничего (как вся страница, спека 26).
5. **Своё** — владелец на своём профиле видит вкладку и при выключенной настройке, с
   пометкой «Видно только вам» и ссылкой на настройку.

## 3. Данные

`users.favorites_public integer (boolean) NOT NULL DEFAULT 0` — `ADD COLUMN`. better-auth
поле не знает — пишет свой action, как `bio`.

## 4. UI

`AuthorPostTabs` (новая вкладка), страница `app/(public)/authors/[id]/favorites/page.tsx`,
переключатель — в форме профиля. Макет вкладки — уже есть.

## 5. Вне scope

Публичные подборки (коллекции), счётчик «в избранном у N» на посте.

  совсем, а пункт спеки 30 закрываем как «не делаем».
