# 38. Фото внутри текста поста

| | |
|---|---|
| Статус | черновик — решения предложены, не обсуждены |
| Lifecycle | `post.md` — раздел «Галерея» |
| Источник идеи | спека 30, «Не сделано»: в макете фото стоят посреди текста |
| Зависит от | 08 (markdown), 14 (редактор), 16 (галерея), 30 (мозаика после текста) |

## 1. Цель

Текст поста — один markdown, галерея — отдельная таблица, и на странице мозаика идёт
после текста. В макете фото и подписи вставлены между абзацами. Нужно ставить фото из
галереи в нужное место текста.

## 2. Решения (предложены)

1. **Ссылка на фото галереи** в markdown — `![подпись](gallery:<imageId>)`. Внешние
   картинки по URL по-прежнему запрещены: только фото своей галереи.
2. **Рендер** — `gallery:<id>` заменяется фото 1600/800 (`srcSet`), с подписью и ссылкой
   на страницу фото (спека 30, шаг 7). Чужой или удалённый id — ничего не выводит.
3. **Мозаика после текста** показывает только фото, которых нет в тексте. Все в тексте —
   мозаики нет. Листание на странице фото — по всей галерее, как сейчас.
4. **Редактор** — кнопка «Фото из галереи» в панели MDXEditor: выбор миниатюры
   вставляет блок. MDXEditor сейчас не разбирает картинки (`onError` открывает запасное
   поле, см. CLAUDE.md) — нужен свой image-plugin или кастомный блок.
5. **Удаление фото из галереи** — блоки с ним в тексте пропадают при показе; в
   редакторе — пометка «фото удалено».
6. **Выдержка и время чтения** (`postText.ts`) — блоки фото в текст не считаются.

## 3. Данные

Нет новых таблиц. Ссылки живут в `posts.content`. Валидация при сохранении: каждый
`gallery:<id>` — фото этого поста.

## 4. UI

Рендер markdown — компонент текста поста (`react-markdown`, кастомный `img`), редактор —
`domains/posts/components/editor/`. Макет — есть (фото посреди текста на странице поста).

## 5. Вне scope

Несколько фото в ряд внутри текста, обтекание текстом, видео.

## 6. Открытые вопросы

- Синтаксис `gallery:<id>` устраивает или ставить фото «после абзаца N» без правки
  markdown?
- Если MDXEditor не даст свой блок картинки малой кровью — согласны вставлять через
  запасное markdown-поле?
