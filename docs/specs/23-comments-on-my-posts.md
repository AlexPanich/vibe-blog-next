# 23. Комментарии к моим постам

| | |
|---|---|
| Статус | done |
| Lifecycle | `comment.md` — кто что видит |
| Источник идеи | next-2, спека 12 «Комментарии в личном пространстве» (вторая половина) |
| Зависит от | 15 (комментарии), 16 (комментарии к картинкам) |

## 1. Цель

«Мои комментарии» в кабинете уже есть. Не хватает обратной стороны: что читатели написали
под моими постами — сейчас это собирается обходом страниц постов или по колокольчику
(спека 20), который хранит только 200 последних событий.

## 2. Решения

По аналогии с next-2, приняты как есть:

1. **Вкладки в `office/comments`:** «Мои» (как сейчас) и «К моим постам» (`?tab=received`).
   Отдельного пункта меню нет.
2. **«К моим постам» — чужие комментарии** под всеми моими постами и картинками их
   галерей; свои ответы в своих постах сюда не попадают — они во вкладке «Мои».
3. **Только чтение** (next-2): автор поста чужие комментарии не правит и не удаляет. Из
   строки — «Ответить» (переход к `#comment-<id>` на странице поста) и жалоба там же, на
   странице поста (спека 18): у автора поста на неё уже есть право.
4. **Посты в любом статусе.** Комментарии остаются, когда пост уходит из ленты (архив,
   блокировка, снятие). Ссылка — по правилу уведомлений (спека 20, п. 10): пост
   опубликован — на страницу поста, иначе — в кабинет поста.
5. **Скрытые модератором** показываются заглушкой «Скрыт модератором» без текста и без
   причины (причину видит только автор комментария); удалённые («заглушки» с ответами) —
   не показываются.
6. **Строка:** аватар и имя автора, обрезок текста, пост (и «к фото»), «N минут назад»
   через `LocalDate`, «изменён». Свежие сверху.
7. **Порциями по 20** с «Показать ещё» по курсору `id` — список у активного автора растёт
   быстрее «Моих». «Мои» пока остаются как есть (весь список).
8. **Счётчики на вкладках** — всего записей, как «Всего: N» сейчас.

## 3. Данные

Новых таблиц нет. Индекс `comments_post_idx` уже есть; выборка — `comments` ⨝ `posts` по
`posts.userId = я`, `comments.userId <> я`, `deletedAt IS NULL`.

## 4. UI

- `office/comments`: `.ui-filter` с вкладками «Мои» и «К моим постам».
- Пусто: «Под вашими постами пока нет комментариев».

## 5. Вне scope

Удаление и правка чужих комментариев автором поста, ответ прямо из кабинета, фильтры по
посту, отметка «прочитано» (это делает колокольчик).

## 6. Что показала проверка

Прогон в браузере на тестовых данных (22 видимых комментария bob к посту alice, скрытый,
удалённый, свой комментарий alice, комментарий some к фото с правкой, комментарий alice к
посту bob на модерации; после прогона удалены): вкладки «Мои · 1» / «К моим постам · 24»,
первая порция 20, «Показать ещё» добавляет 4 без дублей и пропадает; скрытый — заглушка, его
текста и своего комментария нет в HTML; удалённого нет; «к фото» и ссылка на страницу
картинки с `#comment-<id>`; у bob — ссылка в кабинет поста без «Ответить»; у some —
«Под вашими постами пока нет комментариев»; битый `?tab=` — «Мои». Всё сходится.

- Пункт меню «Мои комментарии» переименован в «Комментарии», заголовок страницы тоже: под
  ним теперь обе вкладки.
- Строка — автор с аватаром и пост в мета-строке, как в очереди жалоб (`CommentReportRow`):
  аватар третьим ребёнком `.ui-row` ломал раскладку `space-between`.
- Курсор и порядок — по `comments.id`, а не по `createdAt`: id растёт вместе с датой, а
  курсор по нему стабилен.
- Заглушка скрытого — курсивом в строке, без `ui-note`: у автора поста нечего показывать,
  кроме самого факта.
