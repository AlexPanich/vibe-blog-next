## 1. Цель

Сейчас рубрику можно переименовать и удалить (`TagRow`). Дубли вида «Путешествия» /
«путешествие» приходится удалять, теряя рубрику у постов. В макете — слияние и подсказка.

## 2. Решения (предложены)

1. «Слить» — выбрать целевую рубрику; у постов исходная заменяется целевой (без дублей в
   `post_tags`), подписки `tag_follows` переносятся (без дублей), исходная удаляется. Всё в
   одной транзакции. Права — те же, что у удаления (модератор, админ).
2. Старый slug исходной: редирект `/tags/<old>` → `/tags/<new>`? Нужна таблица алиасов —
   открытый вопрос; без неё старые ссылки дают 404.
3. Похожие — подсказка, не автоматика: рубрики, у которых `nameKey` совпадает после
   нормализации (`ё → е`, без окончаний -ия/-ие/-и/-ы — простая обрезка) или расстояние
   Левенштейна ≤ 2 при длине ≥ 5. Считается в JS при открытии страницы (рубрик десятки).
4. Строка-дубль подсвечена `--sun-soft`, рядом «похожа на «…»» и кнопка «Слить» сразу с
   выбранной целью.

## 3. Данные

Новых таблиц нет (кроме алиасов, если решим, — `tag_aliases (slug, tag_id)`).

## 4. UI

«Модерация — Рубрики»: в строке действий — переименовать, слить, удалить; диалог слияния —
выбор цели с поиском.

## 5. Вне scope

Иерархия рубрик, автоматическое слияние.
