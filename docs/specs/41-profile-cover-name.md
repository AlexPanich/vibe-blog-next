# 41. Профиль: своя обложка и имя в родительном падеже

| | |
|---|---|
| Статус | черновик — решения предложены, не обсуждены |
| Lifecycle | `user.md` — поля профиля, удаление чужой обложки admin-ом |
| Источник идеи | спека 30, «Не сделано»: своя обложка профиля; «Ещё у Ани» вместо «Ещё у автора» |
| Зависит от | 02 (журнал admin), 11 (профиль), 17 (аватары), 30 (шапка профиля, «Ещё у автора») |

## 1. Цель

Две правки профиля, обе — новые поля в `users`:

- баннер профиля сейчас — обложка последнего поста автора или цветная плашка; в макете —
  своя картинка;
- под постом блок «Ещё у автора» — в макете «Ещё у Ани»: имя склонять мы не умеем.

## 2. Решения (предложены)

**Обложка**

1. Загрузка в `office/profile` рядом с аватаром: jpeg/png/webp до 5 МБ, варианты по
   ширине 1600 и 800 (`saveImageVariants`), кадрирование — `cover` по центру, как
   показано на странице.
2. Нет своей — как сейчас: обложка последнего поста, без неё — плашка.
3. Удалить свою — кнопкой; admin удаляет чужую с записью в журнал, как аватар
   (`avatar_removed` → новый тип `cover_removed`, уведомление владельцу).

**Имя в родительном падеже**

4. Необязательное поле «Как вас называть в подписях: „Ещё у …“» — одно слово или два,
   до 40 символов, подсказка «Ани», «Марата Хасанова».
5. Где используется — «Ещё у <имя>» под постом. Нет поля — «Ещё у автора», как сейчас.
   Автоматического склонения нет: для имён оно ошибается.

## 3. Данные

`users.cover_key text NULL`, `users.name_genitive text NULL` (CHECK длины на колонке) —
`ADD COLUMN`. better-auth поля не знает: пишут свои actions, как `bio`. `getAuthor`
отдаёт оба поля.

## 4. UI

`AuthorHead` (баннер), форма профиля в кабинете, `app/(public)/posts/[id]/page.tsx`
(заголовок «Ещё у …»), admin — `office/admin/users`. Макет — уже есть (баннер профиля).

## 5. Вне scope

Позиция кадра обложки (перетаскивание), склонение в других местах интерфейса.

## 6. Открытые вопросы

- Склонение: поле, которое заполняет сам человек, или вообще отказаться от «Ещё у Ани»?
- Нужна ли кнопке удаления чужой обложки причина, как при удалении аватара?
