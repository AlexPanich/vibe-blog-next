# 10. Избранное

|---|---|
| Статус | done |

| Источник идеи | next-2, спека 26 «Избранное» |

Решения приняты без обсуждения (человек попросил работать без остановки), подтверждены на проверке 2026-10-27.

## 1. Цель

Читатель откладывает пост «на потом» и находит его в кабинете.

## 2. Решения

1. **Закладка принадлежит человеку**: публичного счётчика нет, никто не видит чужое
   избранное.
2. **Добавить можно только опубликованный пост**, свой тоже — это не оценка, смещать
   нечего. Проверка статуса — в той же транзакции, что запись.
3. **Кнопка — на странице поста**: «В избранное» / «В избранном». Своё состояние грузится
   после гидрации, как своя оценка (спека 07): публичная часть сессию на сервере не
   читает. Гость видит ссылку на вход. В карточке ленты кнопки нет — пришлось бы
   запрашивать состояние каждой карточки.
4. **Список — `/office/favorites`**, пункт «Избранное» в группе «Кабинет» для любого
   вошедшего. Свежие закладки сверху, кнопка «Убрать» в строке.
5. **Пост ушёл из ленты — закладка остаётся, но в списке не показывается**; вернётся пост —
   вернётся и в списке. В счётчике списка — только видимые.
6. Код — в домене `posts` (`postFavoriteActions.ts`, `PostFavoriteButton`): URL раздела
   не создаёт веток в домене.

## 3. Данные

`post_favorites`: `userId`, `postId`, `createdAt`, PK `(userId, postId)`.
