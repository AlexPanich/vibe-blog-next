# Спеки

Каждая фича — `NN-name.md` (контракт и решения) и, где нужен, `NN-name.plan.md` (план).
Отклонения, найденные при реализации и проверке, дописаны в конец спеки.

## Одна фаза — одна сессия

Цена хода растёт с размером контекста, а фича целиком в одной сессии доходит до 300k+.
Поэтому фазы разделены, и между ними — `/clear` (или хотя бы `/compact`):

1. **Спека** — обсуждение и решения → `NN-name.md`.
2. **План** — по спеке → `NN-name.plan.md`.
3. **Реализация** — новая сессия: «реализуй `docs/specs/NN-name.plan.md`». Можно на Sonnet:
   решения уже приняты.
4. **Проверка** — в браузере через субагента (скил `app-run`), отклонения — в конец спеки.

Всё, что нужно следующей фазе, должно лежать в файлах спеки и плана, а не только в
переписке: новая сессия видит только их.

Большие документы (`docs/lifecycles/*`, длинные спеки) не читать целиком: найти раздел
через `grep -n` и прочитать его по смещению.
