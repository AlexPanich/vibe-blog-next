# 39. Ручной «Выбор редакции»

| | |
|---|---|
| Статус | реализовано — `39-editors-pick.plan.md`, проверка — шаг 11 |
| Lifecycle | `post.md` — новый раздел «Выбор редакции», «Кто что видит» |
| Источник идеи | спека 30, «Не сделано»: выбор редакции — не редакция, а лучшая оценка недели |
| Зависит от | 07 (оценки), 20 (уведомления), 30 (`homeFresh`, `PostFeatured`) |

## 1. Цель

Метка «Выбор редакции» на главной сейчас честно не выбор: это пост с лучшей средней
оценкой за 7 дней (`homeFresh` в `homeBoard.ts`). Нужно дать редакции выбирать руками,
оставив автоматику запасным вариантом.

## 2. Решения (обсуждены)

1. **Кто выбирает** — moderator и admin. Кнопка «Выбрать для главной» на странице
   опубликованного поста (видна только им) и в очереди модерации у опубликованных.
2. **Один выбранный пост** в каждый момент: новый выбор снимает прежний. Выбор действует
   7 дней с момента выбора, потом главная возвращается к автоматике (обсуждено: не
   бессрочно — забытый выбор не висит месяцами).
3. **Автоматика** — без ручного выбора как сейчас: лучшая оценка недели. Метка в этом
   случае — «Лучшее за неделю», а «Выбор редакции» — только у ручного (обсуждено).
4. **Пост ушёл из публикации** — выбор сбрасывается: `changePostStatus` при переходе из
   `published` обнуляет `featured_at` / `featured_by` в той же транзакции. Вернувшийся в
   публикацию пост (разблокировали) на главную сам не возвращается (обсуждено).
5. **Автору** — уведомление `post.featured` «Ваш пост выбрали для главной».
6. **Снять с главной** (обсуждено) — у выбранного поста вместо «Выбрать для главной»
   кнопка «Снять с главной»: обнуляет `featured_at` / `featured_by`, главная сразу
   переходит на автоматику. Уведомления автору при снятии нет.
7. **История** — записи в `post_moderations` не нужны; храним, кто и когда выбрал.

## 3. Данные

`posts.featured_at integer NULL`, `posts.featured_by integer NULL` (`ADD COLUMN` руками).
Текущий выбор — `published`-пост с наибольшим `featured_at` за последние 7 дней. Выбор
нового поста обнуляет колонки у прежнего (одна транзакция) — в базе ненулевой
`featured_at` максимум у одного поста. Тип уведомления —
только в TS.

## 4. UI

`homeBoard.ts` (`homeFresh`), `PostFeatured` (подпись метки), кнопка — домен `posts`,
action в `postModerationActions.ts`. Макет — кнопка на странице поста для модератора.

## 5. Вне scope

Несколько выбранных постов, расписание выбора, подборки.

## 6. Открытые вопросы

Нет: срок (7 дней), подпись автоматики («Лучшее за неделю»), снятие вручную (да) и
возврат в публикацию (выбор сброшен) обсуждены 2026-11-09.
