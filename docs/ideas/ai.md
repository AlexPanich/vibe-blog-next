# Идеи: ИИ в блоге

Бэклог вариантов, как показать интеграцию ИИ в демо. Не спеки: решения не приняты. Вариант,
который берём в работу, получает свою спеку в `docs/specs/` и ссылку здесь.

Порядок — по соотношению «эффект на демо / трудозатраты».

## Сильные кандидаты

### 1. ИИ-ассистент модератора — спека 54

Пост уходит на модерацию → LLM читает его вместе с правилами (`src/content/rules.md`) и отдаёт
структурированный разбор: нарушения с цитатами, риск, короткое резюме, черновик комментария
к отклонению. Модератор видит разбор на странице ревью; решает всегда человек.

- Опирается на готовое: lifecycle поста, ревью, живой канал.
- Показывает structured output и human-in-the-loop.
- Расширение: то же для жалоб на комментарии и посты.

### 2. Помощник автора в редакторе

Кнопки в MDXEditor: «предложить заголовок», «написать lead», «подобрать рубрики» (только из
существующих тегов — не плодить новые), «проверить орфографию и стиль». Для путешествий —
«извлечь точки маршрута из текста» → места с координатами ложатся в `post_route_points`.

- Самое заметное на демо: ответ стримится прямо в интерфейс.

### 3. Семантический поиск и «похожие посты»

Эмбеддинги постов в SQLite (`sqlite-vec` или BLOB + косинус в JS — на демо-объёме хватит).

- Блок «Похожие посты» под статьёй.
- Поиск по смыслу в `HeaderSearch`: «куда съездить зимой у моря» находит посты без этих слов.
- Заодно обходит побайтовый `LIKE` по кириллице.
- У Anthropic нет своих эмбеддингов — нужен отдельный провайдер (Voyage) или локальная модель.

### 4. «Спросить блог» (RAG-чат)

Чат в публичной части: отвечает по опубликованным постам, со ссылками-цитатами на источники.
Строится на эмбеддингах из п. 3.

- Самое эффектное, но нужен жёсткий rate limit на гостей (скил `rate-limit`) и контроль
  стоимости.

## Поменьше, но полезно

5. **Авто-TL;DR поста** — генерация при публикации, хранится в БД, показывается в карточке
   ленты и в RSS.
6. **Alt-текст и подписи к фото** — vision-модель описывает загруженную картинку в процессе
   обработки `sharp` (`shared/images.ts`). Доступность и SEO.
7. **Подсказка admin о дублях рубрик** — «Горы» / «горный туризм» → предложение merge (слияние
   уже есть, спека 47).
8. **Черновик ответа на комментарий** для автора поста.

## Рекомендуемый порядок

1 → 2 → 3 (→ 4). Первый показывает серверную интеграцию, второй — клиентский UX со стримингом,
третий — «настоящий» ML поверх базы и открывает дорогу к RAG.

Провайдер — Claude API (`@anthropic-ai/sdk`), ключ — через `src/config/`.
